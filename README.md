
# Jogo da Velha

Este projeto é um jogo da velha desenvolvido com HTML, CSS e JavaScript.

## Como jogar

- Dois jogadores participam da partida.
- O primeiro jogador utiliza o símbolo X.
- O segundo jogador utiliza o símbolo O.
- Vence quem conseguir formar uma linha com três símbolos iguais, na horizontal, vertical ou diagonal.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
